How to Use this Browser

Use the Up, Dn, PgUp/^R, PgDn/^C, Home, and End keys to scroll the current document. Left and right arrows move the highlighted selection to the next hyperlink (note: link may be off the screen). Press Enter (CR) to select a highlighted link. Press ESC to go back to the previous page. ESC from the main page exits the browser. You can run Setup to change this browser's position in the boot action list.
