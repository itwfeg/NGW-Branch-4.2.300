
Note about the gcd layouts and images directories:

The XML files are in pairs: TLXML11.xml and TLXML12.xml for 'meat', 21 and 22 for 'bakery', 31 and 32 for 'deli', etc.

The filename ending with a '1' is the layout for full-screen mode.  All of these layouts
are identical except for the image names.

The filename ending with a '2' is the layout for embedded video mode.  All of these layouts
are identical except for the image names.

-----------------------------------------------------

Some of the images have transparency in them.  These will need to be
edited with something more sophisticated than Paint so you do not
lose the transparency. GIMP is one such tool you can use.
