Board Module Name: Salsa
Project Name: Salsa
Chipset Module Name: GX3
CPU Module Name: GX3
The Demonstration BIOS is called Salsa.BIN and is 512K in size, filling the ROM on the system board. It was created with the following tools:

  Microsoft Macro Assembler 6.14.8444
  Microsoft Segmented Executable Linker version 5.31.009
  Microsoft 32-Bit Incremental Linker Version 5.00.7022

BUILD NOTES: This module builds with MASM. TASM builds will overflow F000h.

NOTES ON EB2K533 FEATURES

  • ACPI. Includes S0, S1, S3 (STR), S4 (OS), S5 states.
  • APM. Full on, Standby, Suspend (STR), Soft-Off.
  • PS2 keyboard, USB keyboard, PS2 mouse, and USB mouse.
  • UDMA modes 0-4
  • USB Mass Storage (available seperately)
  • Firmbase Technology with 1-256ms (variable) timebase
  • Quick boot (~2 seconds typical)
  • Plug-n-Play
  • Reflash
  • Manufacturing Mode: MM is available on this platform.
  • WinCE: The standard integrated WinCE loader is enabled.
