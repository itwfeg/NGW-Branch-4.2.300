srvany can be used to make any standalone executable a Windows service. An article about it can be found here:

http://support.microsoft.com/kb/137890

The article indicates that it's for Windows NT but we have used it on versions including Windows 7, XP, and XP
embedded.

Currently we use it specifically for the GoAhead web server but it can be used for anything. Please check out
GoWebs registry key for further details.
