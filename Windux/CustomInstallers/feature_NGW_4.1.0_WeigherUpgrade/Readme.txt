
Wrapper weigher upgrade for application version 4.1.x:
------------------------------------------------------

This upgrade package upgrades the weigher firmware for a wrapper to
firmware version 1.4.

This addresses SOF-4427, where weigher boards were reporting
"65535.65535" for the firmware version.

The upgrade process executes the following steps:

  1) Kill chobart_d and scaleui
  2) Rename chobart_d to a backup name
  3) Copy “new” chobart_d into /usr/bin
  4) Copy config_linux.dat to /etc/hobart
  5) Rename /etc/hobart/configdebug.dat to a backup name.
  6) Copy a "new" configdebug.dat to /etc/hobart (with WeigherCommManager.WeigherSystemStatus enabled)
  7) Copy XPEWeigher.zip to /usr/local/hobart/download
  8) Reset the USB hub via:
     a) /bin/echo 0 >>  /usr/local/gpio/hub1_enable/value
     b) Sleep 100 ms
     c) /bin/echo 1 >>  /usr/local/gpio/hub1_enable/value
  9) Re-start chobart_d and scaleui
 10) Wait for XPEWeigher.zip to be removed from the download directory.
 11) Reset the USB hub via:
     a) /bin/echo 0 >>  /usr/local/gpio/hub1_enable/value
     b) Sleep 100 ms
     c) /bin/echo 1 >>  /usr/local/gpio/hub1_enable/value
     Verify that the new firmware reports "1.4" as the version,
     by checking the debug.log file generated by chobart_d.  It will contain a line like this:

     [UsbWeigherSystemStatus][0:02:09:474] softwareWeigherVersion: V::0.1.4.0.0

 12) Kill chobart_d and scaleui
 13) Put the original chobart_d back in /usr/bin
 14)    Put the original configdebug.dat in /etc/hobart
 15) Re-start chobart_d and scaleui
 16) Re-boot the wrapper console
