Hardware Summary

The AMD Geode LXDB800 System Platform, code-named "Salsa", is AMD's answer for the development needs of the information appliance market. The Salsa enables system designers to write and test code for AMD's mobile, thin-client, and embedded applications. The ability to perform such development in a stable and highly observable system shortens the time required to bring devices to production.

The Geode GX533@1.1W processor is targeted and optimized for the broadband based information appliance market. When coupled with CS5535/CS5536 I/O companion device, the Geode GX provides optimal performance while balancing overall power consumption.

The Salsa platform includes four 3.3V PCI slots and an LPC (Low Pin Count) interface. The four USB ports allow for both Legacy USB keyboard and mouse support as well as support for boot from USB mass storage devices including, HDD, FDD, CDROM, CompactFlash readers, memory stick and more. The board also provides a standard 40-pin IDE header, audio jacks, and a wide range of jumper and software selectable options allow for a variety of specific validation and development configuration options.

The optional Wren I/O card incorporates an NSC PC87417 Super I/O enabling support for a floppy drive, two additional RS-232 serial ports, one LPT port, Port 80 display, PS/2 keyboard and mouse connectors and sockets for an additional flash ROM.

The limited boot loader (XpressROM) provides basic hardware validation but does not address modern software initiatives, including automatic PCI interrupt assignments, comprehensive PCI device enumeration, support for a wide range of hard drives, etc. General Software's Embedded BIOS 2000, a full-featured firmware platform that supports all modern operating systems and industry initiatives, while keeping an embedded focus, has replaced the XpressROM on this platform. General Software's 32-bit Firmbase(R) technology has replaced AMD's proprietary 16-bit VSA2 on the Salsa as well as all Geode designs.

Availability

AMD's Geode LXDB800 development platform is available for purchase. The design schematics and bills of material are available upon request to companies interested in modifying the design to meet specific application and product requirements. For more information please contact AMD.

Firmware Summary

General Software has provided an adaptation of its Embedded BIOS(R) 2000 for demonstration use on this platform. AMD's XpressROM was developed as a board bring-up BIOS for internal validation and was not intended for general OEM use. Now OEMs can choose General Software for its solid track record of superior firmware technical capabilities, high level of customer service, and superior product offering for embedded.

Embedded BIOS 2000 provides the industry-standard building blocks necessary to initialize the chipset, memory, processor, and other hardware components of the board. In addition, it supports industry-standard operating systems with functionality including APM, PnP, El Torito, PMM, USB, and a host of other capabilities.
