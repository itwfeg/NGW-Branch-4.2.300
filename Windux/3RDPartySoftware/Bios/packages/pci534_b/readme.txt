README.TXT - Package Information File.

FILE DESCRIPTION.
    This file contains state and revision information relative to this module.

    The Module State section describes the current state of this module.
    The state section should be changed and this file checked in whenever
    this module transitions from one state to another. The following states
    are supported:
        DEVELOPMENT - Under development; may be modified.
        REVIEW      - Under code review; may be modified to conform to code
                      review findings.
        TEST        - In a test cycle; do not modify unless directed.
                      Check executable files into the EB2K533 tree.
                      Modifications must be coordinated with test cycles.
        SHIPPED     - On the shelf and shipped; do not modify.
        HALTED      - Development has halted; do not modify.
